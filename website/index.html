About this project

Amazon CloudFront

Delivers the website and images from edge locations closer to visitors.

Amazon EC2

Runs the web server (Apache) and the admin backend.

Amazon S3

Stores the photographs in a private bucket.

AWS IAM

Controls who and what can access each resource.
